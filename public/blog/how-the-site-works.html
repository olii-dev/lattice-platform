Meet the Lattice platform

Product Sep 14, 2026

Lattice is a simple place to try our small language models and use them in your own projects.

Chat in your browser

Open the chat, choose Quark or Spark, and start a conversation. Guest access lets you try it immediately, while a free account gives you higher limits and saved access to your API keys.

Build with the API

Create an API key from your dashboard and connect through an OpenAI-compatible endpoint. That means many tools can use Lattice with only a small configuration change.

Follow the models

Benchmarks, model notes and release posts stay public, so you can see what each model is good at before choosing one.

Try it now in Chat, read the Docs, or create a free account.
