Lattice is a platform now

Releases Sep 14, 2026

Lattice has a proper home. The site has moved off Vercel and onto lattice.mebbo.cloud, and it's no longer just a chat box bolted to a landing page: there are real accounts, self-serve API keys, an OpenAI-compatible API, and a chat that's actually pleasant to use. Everything Quark and Spark can do, you can now wire into your own stuff for free.

Why rebuild it

The old setup was a Vercel frontend with a hardcoded shared key between it and the GPU server. Fine for a demo, but it meant nobody could touch the API except the site's own chat, and "accounts" were never going to happen on that stack. If people were going to actually use these models in their own little scripts, whatever - they needed their own keys, their own limits, and a dashboard to see what they'd used. So the whole thing got rebuilt properly.

What you get

  • Real accounts. Sign up with an email, verify it, and you're in. No waitlist, no invite codes.
  • Self-serve API keys. Create up to five keys from the dashboard, name them, revoke them yourself. Keys are shown once and stored hashed - lose one and you just make another.
  • An OpenAI-compatible API. Point anything that takes a base URL and a key at https://lattice.mebbo.cloud/v1 and pick lattice-quark-1.5b or lattice-spark-1.5b. Docs are at /docs.
  • A new chat. Model switching between Quark and Spark, chat history saved per browser, and you don't even need an account - guests get ten messages an hour to try things out. Signing up lifts the limits.
  • A usage dashboard. Requests per day, characters generated, the lot. If you're burning through your daily limit you'll see exactly where it went.

How it's put together

The site is a Cloudflare Worker with a D1 database for accounts, keys and usage. The models still run on the same Azure T4 VM as before - the worker is just a smart front door: it checks your key, counts your request, and forwards the prompt. Cold starts are still a thing (the models unload when idle and take a minute to warm back up), but the first request warms them for everyone.

Rate limits are simple: 20 requests a minute and 200 a day per API key, 10 messages an hour for guests. Everything runs on one shared GPU, so the limits are there to keep it fair, not to upsell you - there's no paid tier and there isn't one planned.

What's next

The benchmarks and the rest of the blog all came over with the move, and there's an FAQ now for the questions that kept landing in my inbox. Next up is real token streaming in the API - right now stream: true is faked as a single chunk, which works but isn't the real thing.

Go make a key and break something: the dashboard is waiting. Bugs and ideas to the contact page, as always.
