FAQ

What is Lattice?

A research project building small language models in the open. The flagship is Quark, a 1.5B model pretrained and instruction tuned entirely from scratch - no borrowed weights. Spark is a Qwen2.5-1.5B identity fine-tune. Both are free to use here.

Is it free?

Yes. Accounts are free, API keys are free, web chat is free. There are rate limits (20 requests/minute, 200/day per key; 10 messages/hour for guests) because everything runs on one shared GPU. No paid tier exists.

Do I need an account to chat?

No - open the chat page and go. Guests get 10 messages/hour per IP. A free account gets you higher limits, chat history, and API keys.

How do I get an API key?

Sign up, verify your email, then create a key in the dashboard. It's shown once - save it. Full docs at /docs.

Why is the first message slow sometimes?

The models unload from the GPU when idle. The first request after a break reloads them - can take a minute or two. After that, responses are fast.

Can I trust what the models say?

These are 1.5B-parameter models. They're surprisingly decent for their size but they will make things up with confidence. Don't use them where accuracy matters. Check the benchmarks for honest numbers.

Where are the weights?

On Hugging Face: lattice-quark-1.5b and lattice-spark-1.5b. There's also an MLX build of Quark for Apple silicon - see the blog post.

Do you log my chats?

The platform records aggregate usage (request counts, latency, model) for the dashboard and admin abuse controls. Guest chats aren't tied to an identity beyond IP rate limiting. Don't paste secrets into the chat - treat it like any public model.
